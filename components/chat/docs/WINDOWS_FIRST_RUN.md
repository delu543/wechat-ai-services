# Windows 新手：复制一句话，跟着 Codex 做

适用 Windows 10/11 **x64**、官方微信 4.x；当前是**源码预览版**，自动化测试通过不等于
所有微信版本已经实机验证。使用本人有权访问、且已保存在这台电脑上的数据。

## 第一句话发什么

在这台 Windows 电脑的 **Codex 本地任务**中发送下面整段，不是在微信里发送：

```text
我用 Windows 10/11，请帮我在本机安装并使用这个项目：
https://github.com/delu543/wechat-data-extraction
请取得完整源码，读取 AGENTS.md 和 docs/WINDOWS_FIRST_RUN.md，按 Windows 新手流程检查和安装。
需要我本人登录微信或确认隐私操作时，一次明确告诉我下一步；其余能安全代办的步骤由你完成。
如果本地已有这个项目，先检查，不要覆盖已有文件或改动其他项目。
```

如果 Codex 要求选择工作文件夹，选一个专门放这个项目的本地文件夹。已有仓库就打开它。
仅把链接贴进普通网页聊天或远程云任务，不能访问这台电脑的微信。

**不用一开始就登录微信。安装可先完成，账号初始化和日常导出时才需要登录。**
如果已经登录，不用退出或重新扫码；按提示打开任意聊天，保持微信打开即可。

## 你本人只需做这些

1. **登录微信**：等 Codex 提示后，在官方 Windows 微信登录要导出的账号，打开任意聊天。
   不必翻到历史消息，不必逐条点语音，也不必提供截图。登录、扫码、手机确认只能本人做；
   若已登录且微信没有再次要求手机确认，不需要额外拿手机操作。本工具不能绕过微信登录。
2. **第一次明确进入初始化**：安装成功后，按 Codex 提示发送下一行：

   ```text
   $wechat-local-export-setup
   ```

   告诉它要导出的类型，例如“文字和语音”。如果前面已说过，就不必重复。
3. **分别确认两件隐私事项**：先看当前账号和类型范围，确认一次只读初始化；成功后，再
   单独确认创建并保留本机私有解密快照。可以拒绝任一步，拒绝后不会自动继续导出。
4. **提出导出需求**：给准确群名/联系人、时间范围、内容类型和目标格式；普通归档扫描后
   确认数量即可。例如：

   ```text
   把“项目讨论群”昨天 9 点到 18 点的文字导出来，先告诉我数量。
   ```

   只要合并语音文件时可以说：

   ```text
   把“项目讨论群”今天 18:00 到现在的所有语音直接合成 MP4。
   ```

   这条纯语音直接 MP4 请求在账号已就绪、精确匹配且无异常时，无需再说“确认导出”。
   混合归档仍先展示扫描结果并等你确认。Word 是另行转换，不是底层直接导出格式。

**只有遇到时才需要操作**：缺少 Python/VC++ 运行库时确认安装；系统安装器要求时本人
完成安装；Codex 需要本次本地操作权限时审阅相应提示；新 Skill 没有出现时重启 Codex，
回到同一项目继续。不要关闭杀毒、修改执行策略或为省事开启全局无限权限。

## Codex 应如何引导（本项目的 Windows 对话约定）

本节供 Codex 执行，也让用户知道下一步会发生什么。措辞可简化，事实必须来自工具结果。
这是引导规则，不是会自行运行的聊天机器人；适用宿主和用户权限仍优先。
每次只提出当前需要的一项操作/决定。保留同一任务已经给出的群名、时间、类型和有效授权，
不重复索取；省略已通过的步骤，不能把示例中的“同意”当成用户真实授权。

### A. 取得源码、检查安装

仅检查当前指定项目和本项目的固定安装位置；无完整源码时按用户请求取得此仓库，已有
目录/改动不得覆盖。没有本地工作位置或权限就说明需要选择什么，不扫描其他项目。
先读根目录 AGENTS 和本指南；使用 Windows bootstrap `doctor`，不运行 Mac shell/Swift。

首条回复示例：

> 我先检查本机环境并安装项目运行依赖，这一步不读取微信聊天。暂时不用操作微信；需要你登录或确认时，我会告诉你。Windows 目前是源码预览，遇到不支持的微信版本会停止。

用户已明确要求安装时，说明将下载项目固定版本、固定哈希的普通 PyPI 依赖，然后按
既有安装授权运行 bootstrap `install`，不为同一安装重复提问。若仅请求查看状态，不安装。
缺少 CPython 3.12 x64 或 VC++ 运行库时，说明准确缺项、官方来源和影响后取得安装同意；
可由 Codex 在授权范围内完成的下载/命令不让用户抄写。需要人工安装器交互时给出具体动作。
Windows 初始化复用普通运行依赖，不再安装 Mac 的 Frida/Swift。

安装后运行 bootstrap `doctor` 验证；这是**环境就绪**，不是账号已就绪。不要仅凭命令退出
码、文件存在或一条建议就说成功。不要把开发发布检查、GitHub CI 或更新其他仓库加入日常使用。

### B. 登录和当前账号检查

环境就绪后，若用户尚未说明已登录，提示：

> 请在这台电脑的官方微信登录要导出的账号，打开任意聊天并保持微信打开。如果已经登录，不用退出。完成后回复“微信已登录”。

已登录则直接运行普通客户端 `doctor`，不再要求重新登录。Codex 与微信应使用同一 Windows
用户，通常均正常启动；不要要求管理员模式。账户检查失败时，让用户确认目标账号、打开
任意聊天并把窗口置前，再只读重试一次。仍失败就说明当前无法安全绑定，不索取数据库路径、
账号目录、密钥或截图，也不更换账号猜测。窗口置前仅是用户重试动作，不是账号验证证据。

### C. 首次初始化与内容类型

当前账号已有匹配的就绪 profile 且涵盖本次类型时，跳到导出；不要重新捕获密钥。
确实缺少初始化时，普通导出必须暂停，提示：

> 环境已安装，但这个微信账号还没有完成本机初始化，暂不能导出。请在 Codex 发送 `$wechat-local-export-setup`，我会先检查，再请你确认具体操作。

若 Skill 未被发现，只在这种情况下提示重启 Codex 并重新显式调用，不反复重装。
用户已在当前任务显式调用 setup 时，不重复要求调用；调用本身仍不是捕获或快照保留授权。
没有内容类型时只问“这次要导出文字、语音、图片、文件中的哪些？可以多选。”不默认全选。
setup 根据当前类型执行 Windows `doctor` / `prepare`，再展示实际目标类别和数量。

### D. 初始化确认（第一次隐私确认）

用 prepare 的实际结果替换下例花括号；不要展示内部路径、账号标识、salt 或摘要：

> 已检查当前登录账号，要支持{所选类型}，需初始化{实际数据库类别与数量}。我会对该账号的微信进程做一次限时只读检查，保存经过验证、由 Windows 当前用户加密保护的初始化信息；不会改动微信、发送消息或上传内容。这不是只读取某一个群的操作，此步还不会创建明文聊天快照。是否同意本次初始化？

等用户对当前范围明确同意后，setup 才能 `capture --confirm-capture`。微信保持打开；
不要套用 Mac 的退出微信、临时副本或重新扫码流程。捕获失败、账号/目标变化、prepare
超过 15 分钟有效期时，按 Windows setup 规则停止或重新准备并确认，不沿用失效授权。

### E. 快照保留确认（单独第二次隐私确认）

仅在捕获成功后提示：

> 初始化成功。下一步需要把该账号{所选类型}相关数据库的私有解密快照保存在本机，供本次和以后的按需刷新/导出使用。内部快照可能包含该账号其他聊天，实际导出文件才按你指定的聊天和时间筛选。它只允许当前 Windows 用户和系统访问，不上传，也不会自动删除。是否同意创建并保留？

等用户单独明确同意后，才运行 `snapshot --confirm-retain`。第一次初始化同意、安装请求、
“少问我”“全部同意”等提前笼统表述，都不能合并代替这两个针对实际范围的确认。
拒绝保留就不生成快照，并说明已保存的初始化信息仍私有保留，普通导出尚未配置完成。

### F. 验证、继续原来的导出请求

快照成功后运行普通客户端 `doctor`，按真实能力提示：

> 当前账号的{已验证类型}已就绪。请保持微信打开。{已有具体导出需求：我继续按刚才的群名和时间扫描；否则：告诉我要导出的群名、时间和内容类型。}

整体页面 HMAC 尚未全部验证、缺媒体等限制仍须如实告知；不要把初始化成功说成导出成功。
普通归档显示精确聊天、绝对时间（含时区）、各类型数量和首末时间，用户确认该摘要后导出。
纯语音直接 MP4 仍走现有单次高层命令，内部先扫描再严格验证。缺群/时间/类型时仅补问缺项；
同名群必须选择，零条不创建空文件，缺失媒体不得静默跳过或自动改成部分导出。
只返回真正验证成功的本地文件链接和数量，不把聊天正文自动读入 Codex 对话。

### G. 下次使用与失败提示

同一账号通常只需“登录并保持微信打开 → 说群名、时间、类型”。新账号、新增数据库分片、
扩大类型、密钥/格式变化可能需要重新明确 setup。版本不支持时，说明失败阶段和一项可做的
安全动作；无安全重试路径就停止，不反复读取进程、不关闭防护、不转截图/OCR或远程服务。
新电脑缺少历史消息/附件时，用户只能用微信自己的合法同步/下载功能补齐；工具不能恢复
本机不存在的数据。请求上传/总结聊天属于另一项数据使用决定，不包含在本地导出中。
