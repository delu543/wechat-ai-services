# 故障诊断与完整 Word 验收

本表是分类依据，不替代当前用户对账号、临时接入、额外重试或删除的授权。先读任务状态、
进程/锁和最后错误；只修受影响阶段，复用已验证音轨、ASR 块与 Word。

| 表象 | 先核实 | 处理与停止条件 |
| --- | --- | --- |
| 目录分页为 0、缺页或账号不符 | 种子标题/账号绑定、页数、末页 `continueFlag=0`、唯一回放 ID | 不凭标题猜账号；会话过期、验证码、付费或限流暂停。没有完整目录不启动批次。 |
| 进度面板“停止”或当前 0 | 同一任务的锁、进程命令和 cwd、状态文件更新时间、面板自身是否可访问 | 区分面板失联、worker 已结束、worker 卡住；不要只凭 UI 再开一个 worker。 |
| 多场同源网络错误 | 探测与下载是否共用预算、网络出口状态、失败分类及已消耗次数 | 共享故障暂停队列；连通恢复后只恢复受影响项。401/403/429 立即停，不换身份规避。额外尝试需同对象新授权且有界。 |
| 已下载音轨时长与目录差数秒 | 音轨完整解码、源容器时长、目录时长、字节/哈希、partial 是否完整 | 目录可能舍入或过旧；只有源容器与完整解码一致时才复用，不放宽阈值、不盲重下。仍不一致保留 partial 并待审。 |
| 本地 ASR 报 `source_duration_mismatch` | 源音轨验证、PCM 帧数、源媒体时间戳空档、解码命令、ASR schema | 旧解码可能抹去时间轴空档。新版以 `aresample=async=1:first_pts=0` 补静音并用 schema 2 隔离旧缓存；先合成回归，再只重转已验证音轨。已耗尽预算的序号须明确批准后至多加 1 次。 |
| 默认 AAC 解码失败 | 原始字节与重复尝试哈希、独立完整解码、时长及信号窗口 | 不用缺损片段凑完整。平台原生解码器只在独立证据证明可完整解码后用于该场；该路径尚非自动通用兜底。 |
| 文字顺序重复或缺后段 | 冻结目录顺序、回放身份、ASR 分块覆盖、2 秒交叠词时间戳、最后一块 | 用词中点归属交叠，不对整段文字去重；缺块重跑该块，不把前段复制到后段。 |
| Word 有文字但渲染丢中文/空白 | DOCX 正文、打包字体、渲染环境、PDF 页文本与页面图 | 先修渲染器字体设置，不改转写正文；渲染全页自动筛空白/贴边/损坏，异常页及代表页目视。记录自动与人工范围。 |
| 合并 Word 多出空白页 | 相邻场次边界、强制分页、PDF 页文本 | 大合集采用连续章节，不在自然满页后强制分页；重新渲染全页检查，旧候选保留至新候选验收。 |

## 交付核对

1. 冻结目录与末页证明仍在；总数等于唯一回放 ID 数。逐场音轨完整解码、ASR 全块覆盖、
   每份源 Word 正文与转写段落相等，DOCX 哈希与验证记录匹配。
2. 每份源 Word 完成渲染检查并注明方法。自动全页筛查可以替代逐页手工翻看，但不能
   替代异常页与代表页目视，也不能声称人工逐字校听。
3. 用 `python3 wechat_ai.py run replay -- assemble` 只从全部已验源文件构建单份 Word；冻结计划须等于目录重算结果，当前转写须逐段等于已验收源 Word。校验场次顺序、
   总段落数、源清单与合并文件哈希。最终 Word 单独渲染：全页自动检查非空与解码，
   目视首页、目录末、首场、跨场、末页及异常页；大文档用合适字体环境。
4. 面板和交付说明分别报告目录、验证音轨、完整转写、逐场 Word、最终合并 Word、
   待处理失败。最终文字仍是机器识别，专有名词和数字可能有误。
5. 只向用户交其所需 Word。媒体、WAV、PDF、日志和失败证据是中间材料，是否删除按
   当前项目逐项清单、隔离验证和第二次永久删除确认处理；不从“只交 Word”推断删除授权。
